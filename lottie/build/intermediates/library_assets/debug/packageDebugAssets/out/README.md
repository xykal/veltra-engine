# Lottie Assets

Taruh `veltra_launch.json` di sini.

**Spesifikasi (biar ringan & mulus di semua device):**
- Durasi: **1.4 detik** (42 frame @30fps)
- Ukuran file: **maks 400 KB**
- Resolusi canvas: 512 x 512
- Isi: energy ring orbit → logo V pulse → teks STABILIZING
- Ekspor dari After Effects via **Bodymovin** dengan:
  - "Glyphs" OFF (pakai path, bukan font)
  - "Hidden layers" OFF
  - "Original Asset Names" OFF

Kalau file belum ada, `LaunchAnimation` otomatis pakai fallback Compose — app tetap jalan.
